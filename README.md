# Sistema de Barbearia

Projeto próprio desenvolvido para praticar programação e desenvolvimento web.

## Sobre o projeto

Sistema de gerenciamento de serviços de uma barbearia, desenvolvido como projeto prático para aplicar conhecimentos de programação, organização de código e desenvolvimento web.

## Tecnologias utilizadas

- Python
- HTML5
- CSS3

## Funcionalidades

- Gerenciamento de serviços de barbearia
- Organização das informações dos serviços
- Interface desenvolvida com HTML5 e CSS3

## Objetivo

Este projeto foi desenvolvido como parte do meu processo de aprendizado em programação, com o objetivo de praticar lógica de programação, funções, organização de código e desenvolvimento web.
